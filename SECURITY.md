# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue for a security vulnerability. Instead, report it privately via the GitHub security advisory feature:

https://github.com/hurzelpurzel/tekton-tasks/security/advisories/new

You will receive a response acknowledging the report. Please include as much of the following as possible:

- Affected Task and version (`app.kubernetes.io/version` label).
- Steps to reproduce the issue.
- Impact and any suggested fix.

We will coordinate disclosure once a fix is available.
